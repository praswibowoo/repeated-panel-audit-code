# Fixed-evaluation primary audit

Generated by `code/unit_revision_fixed.py` with 100 donor draws per study.

## Evaluation

For each focal study, every nonfocal within-study configuration is evaluated. The set is fixed before control draws. Configurations deleted by a control are projected into the reduced PCA solution.

## Designs

- **A:** full-fit row-count control.
- **Bblock:** full-fit one-configuration exact-size donor.
- **C:** collapsed-fit configuration-count control.
- **H:** exploratory donor-study block; not coherence-balanced.
- **B:** legacy exact-volume whole-configuration matcher.

## Interpretation

- A−Bblock is the primary control-geometry contrast.
- A−C is a secondary protocol contrast.
- Bblock is unit-matched only for single-configuration studies.
- Five single-configuration studies lack an exact-size donor and are reported separately.

## Files

- `common_contrast.json`: designs, contrasts, strata, donor availability, per-study medians, and per-draw values.
- `control_balance.json`: Bblock balance and missing-donor studies.
- `pcoa_contrast.json`: fixed-set Jaccard PCoA sensitivity.
- `rms_sensitivity.json`: fixed-set PCA sensitivity using RMS event drift.
- `sensitivity_no_B208.json`: fixed exclusion of B208.
- `sensitivity_no_unsure_substitutes.json`: fixed exclusion of 13 unsure records and two substitutes.
- `manuscript_values.json`: rounded values used by checks.
