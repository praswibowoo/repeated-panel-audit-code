# Fixed-evaluation primary audit

Generated by `code/unit_revision_fixed.py` with 100 parallel donor draws per study.

## Evaluation

For each focal study, every nonfocal matrix-defined within-study configuration is evaluated. The set is fixed before control draws. Configurations deleted by a control are projected into the reduced solution.

## Designs

- **A:** full-fit row-count control.
- **Bstudy:** full-fit exact-size whole single-configuration donor studies, exhaustively enumerated; primary for eligible single-configuration foci.
- **Bblock:** full-fit one-configuration exact-size donor; secondary, because the donor may be embedded in a multi-configuration study.
- **C:** collapsed-fit configuration-count control.
- **H:** exploratory donor-study configuration block; not coherence-balanced.
- **B:** archived greedy exact-volume whole-configuration matcher.

## Interpretation

- A−Bstudy is the primary whole-study control contrast for 91 eligible single-configuration studies.
- A−Bblock is a secondary configuration-donor contrast for 92 eligible single-configuration studies.
- A−C is a protocol contrast that changes fit weighting, control geometry, reference ordination, and normalization.
- Six single-configuration studies lack a whole-study donor and are reported separately.
- Per-study ratios are descriptive, not calibrated outlier scores.

## Files

- `common_contrast.json`: 2-D designs, contrasts, strata, donor availability, per-study medians, and per-draw values.
- `fixed3d_contrast.json`: fixed-set 3-D PCA sensitivity.
- `control_balance.json`: Bstudy/Bblock balance, donor composition, and missing-donor studies.
- `pcoa_contrast.json`: fixed-set Jaccard PCoA sensitivity.
- `rms_sensitivity.json`: fixed-set PCA sensitivity using RMS event drift.
- `sensitivity_no_B208.json`: fixed exclusion of B208.
- `sensitivity_no_unsure_substitutes.json`: fixed exclusion of 13 unsure records and the two substitutes retained in the curated set.
- `manuscript_values.json`: rounded values used by checks.
